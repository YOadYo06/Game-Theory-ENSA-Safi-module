# Rapport final — sources

Déposer ici les sources LaTeX / Word du rapport final (Gantt inclus).

Sections attendues (guide, grille d'évaluation) :

1. Introduction et problématique
2. Organisation et planification (Gantt prévisionnel + réalisé, rotation des rôles)
3. Théorie : formules clés, hypothèses et limites
4. Méthodologie : fonctions Python, tests, outils agent
5. Résultats des expériences (tableaux, graphes) et analyse honnête des écarts à la théorie
6. Conclusion et lien avec le cours

> Le rapport final doit contenir le Gantt (sections 2) et représenter ~80 % du travail en S6.
